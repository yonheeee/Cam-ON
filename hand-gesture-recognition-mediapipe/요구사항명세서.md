# **개요**

목적, 범위, MoSCoW 우선순위

본 프로젝트는 WebRTC 기반 실시간 화상통화와 MediaPipe 포즈/손동작 인식을 결합해, 키보드 입력으로는 구현 불가능한 신체 기반 상호작용 게임을 제공하는 미니게임 플랫폼이다. 손동작 인식(나루토), 물체 인식(물건 가져오기), 포즈 전달(몸으로 말해요) 세 가지 게임을 통해 카메라 기반 AI 인식의 다양한 활용 방식을 시연한다.

# **기능 요구사항**

### 1. 플랫폼 공통 요구사항

1.1 계정/세션
git
- 회원가입 없음, 코드/링크로 참여, 닉네임 입력, 계정정보 일시적 DB 저장
- 닉네임 중복 시 중복 알림 후 새로 입력받기 (닉네임은 서버 전역에서 유일해야 함)
- 방 생성자가 방장이 되며, 위임 가능함. 방장이 재접속 유예시간(15초) 초과로
강제 퇴장되면, 입장 순서상 다음 참가자에게 방장 권한이 위임된다.
위임 대상자도 연결 끊김 상태라면, 그다음 입장 순번 참가자에게 연쇄적으로 위임된다.
- 세션 식별: 게스트 토큰(UUID) 발급 → sessionStorage 저장 → STOMP 세션 매핑
- 데이터 삭제: 방 종료 시점 즉시 DB 삭제

1.2 카메라/권한

- 입장 시점 카메라 권한 거부 → 입장 자체 차단
- 게임 도중 인식 실패 → 해당 라운드만 탈락/0점, 방은 유지

1.3 네트워크/재접속

- 카메라 연결은 필수이며, 연결이 끊긴 시점부터 15초간 "연결 끊김" 상태 화면 표시
- 15초 내 미복귀 시 해당 참가자는 방에서 강제 퇴장된다
- 카메라/마이크 테스트는 게임 시작 직전에만 수행되므로, 강제 퇴장된 참가자는
다음 게임이 시작되기 전까지만 재입장 가능하다
(게임 진행 중 강제 퇴장된 경우, 해당 게임이 종료될 때까지 재입장 불가)

1.4 공통 세션/준비 상태

- 로그인이 없으므로 준비 상태는 방 참가자 세션 데이터에 소속된다.
- 준비 완료 조건 = 카메라 권한 설정 완료 AND 카메라 인식 테스트 통과
(밝기/화질 부족으로 인식이 안 되는 상태에서는 준비 완료로 전환되지 않음)
- 모든 참가자가 준비 완료 상태여야 게임 시작 가능

3. 누구를 공격할지 지정한다

 |

2-3. 몸으로 말해요 

| 진행규칙 |   1. 사용자가 주제를 선택하고 해당 주제의 제시어가 출제된다.
  2. 제시어는 현재 표현자에게만 보여진다.
  3. 표현자는 마이크 없이 행동으로만 설명한다.
  4. 다른 참여자는 채팅으로 제시어를 맞힌다.
  5. 참가자 전원이 한 번씩 표현하면 한 라운드가 종료된다.
  6. 각 표현 턴의 제한시간은 1분이다.  |
| --- | --- |
| 인식 요구사항 | 없음. 채팅 텍스트 매칭 방식. 공백과 보이지 않는 제어문자를 제거하고 영문 대소문자를 무시한 뒤 완전 일치 여부를 판정한다. 특수문자와 이모지는 제거하지 않으므로 정답과 정확히 일치해야 한다. 오타와 유사어는 허용하지 않으며, 정규화 결과가 빈 문자열이면 정답으로 인정하지 않는다. |
| 점수/승리조건 | 정답 시 표현자와 최초 정답자가 각각 1점을 얻는다. 라운드 종료 시 해당 라운드 점수와 누적 점수를 공개하고, 설정한 라운드 종료 후 누적 점수로 최종 순위를 정한다.  |
| 예외 처리 | 출제자가 연결 끊겼을 때 |
| 라운드 범위 | 3, 5, 7, 9라운드 중 선택  |
| 인원 수 범위 | 최소 3명 ~ 최대 4명 |
