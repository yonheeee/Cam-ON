# 몸으로 말해요 화면 설계 메모 (예측 초안)

닌자와 달리 프론트 코드가 아직 없어서(`frontend/src/features/charades` 폴더 자체가 없음), 아래는
요구사항명세서 기준으로 "이런 화면/상태가 필요할 것 같다"는 예측입니다. 배경 후보 이미지는 이미
6종(bright/coral/depth/lavender/quizshow/teal, `public/assets/charades-bg-*.png`)이 테스트돼 있어서
그중 하나를 고르면 될 것 같아요.

## 규칙 기준 확정 요소 (요구사항명세서 기준, 재확인 필요)

- 표현자 1인이 마이크 없이 몸으로 제시어 설명 → 나머지 참가자가 채팅으로 정답 시도
- 정확히 맞춘 채팅 제출자가 정답 처리
- 인식 대상 없음(AI 서버 관여 X) — 전부 Spring `/api/...`, `/ws/rooms/{roomId}` 처리
- 3~4인, 3~10라운드

## 역할별로 화면이 갈려야 함 — 여기가 닌자와 제일 다른 지점

닌자는 전원이 같은 화면(캠 그리드 + 공용 술법 패널)을 보지만, 몸으로 말해요는 **표현자만 제시어를
알아야** 하므로 최소 2가지 뷰가 필요합니다.

- **표현자 화면**: 제시어 노출(카드 형태), 정답 채팅 내용은 안 보이거나 흐리게(스포일러 방지 불필요 —
  본인이 답을 알고 있으니). 대신 "누가 몇 명 맞췄는지" 진행 상황 정도만.
- **관전자/추측자 화면**: 제시어 숨김(placeholder, 예: "???"), 채팅 입력창 + 채팅 로그, 표현자 캠이
  메인으로 크게.

## 아직 안 정해진 것

- **채팅 공개 범위**: 오답도 전원에게 실시간으로 보이는 공개 채팅(스크리블 스타일, 서로 눈치싸움 재미)
  vs 정답 시도가 본인에게만 보이는 비공개 제출? 공개가 더 재밌긴 한데, 오답이 계속 보이면 표현자가
  힌트를 흘리게 될 수도 있음.
- **정답 노출 처리**: 누군가 정답을 맞히면 채팅창에 그 단어가 그대로 남아서 늦게 들어온 사람이 스크롤로
  치팅 가능 → 정답 확정 순간 채팅을 잠그거나(라운드 종료), 정답 텍스트를 마스킹할지 정해야 함.
- **정답자 없이 시간 초과**: 이 경우 화면에 정답 공개를 어떻게 보여줄지(표현자만 알던 제시어를 전원에게
  공개하는 연출), 표현자 채점(0점?)도 명세 재확인 필요.
- **표현자 순번 전환**: 라운드마다 표현자가 바뀔 텐데, "다음 표현자는 나입니다" 예고 화면이 필요한지,
  아니면 라운드 시작과 동시에 바로 전환되는지.
- **제시어 카드 디자인**: 닌자의 술법 카드처럼 픽셀 아케이드 톤 카드로 통일할지, 아니면 퀴즈쇼 느낌
  배경(charades-bg-quizshow.png가 있는 걸 보면 이미 그 방향 고려 중인 듯) 위에 다른 톤으로 갈지.
- **채팅 입력 UI 위치**: 캠 그리드 하단 고정 바 vs 사이드 패널. 4인 캠 + 채팅 + (표현자 화면의 경우)
  제시어 카드까지 한 화면에 다 들어가야 해서 레이아웃 밀도가 닌자보다 높음 — 우선순위 정해야 함
  (캠이 메인, 채팅이 보조라고 가정하고 초안 잡을지 확인 필요).
- **점수/순위 화면**: 닌자의 `ninja-battle__ranking`과 톤을 맞출지, 코스 전체 누적 점수(요구사항명세서의
  "코스 전체 누적 점수 계산")까지 이 화면에서 같이 보여줄지.
- **최종 배경 이미지 선택**: 6개 후보 중 확정 필요.
