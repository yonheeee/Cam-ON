# 닌자 게임 화면 설계 메모

## 확정된 것

1. 손동작을 가장 빨리 완성한 사람이 공격권을 갖는다.
2. 따라 해야 할 손동작은 화면에 이미지로 보여준다.
3. 참여자들의 MediaPipe 좌표를 캠 화면 위에 같이 보여준다.
4. 지금 완성해야 할 술법 중 얼마나 진행됐는지 참여자들에게 보여준다.
5. 공격받은 만큼 HP 바가 줄어든다.
6. 대기 화면 배경을 `ninja-background-v2-test.png`로 교체 완료 ([theme.css:232](frontend/src/theme.css:232)).
7. "손동작으로 콤보를 완성해 공격권을 노려보세요" 안내 문구 삭제 완료.

## 열린 질문 1 — 공격 대상 지정 방식

| 방식 | 장점 | 단점 |
| --- | --- | --- |
| 다른 참가자 캠 화면 클릭 | 직관적, 추가 인식 로직 불필요 | 마우스 입력이라 "몸으로 하는 게임"의 일관성이 깨짐 |
| 숫자 키 입력 | 구현 간단, 클릭보다 빠름 | 역시 키보드 입력이라 컨셉과 안 맞음 |
| 손가락 개수(1~4)를 MediaPipe로 인식 | 손동작만으로 완결, 컨셉 일관성 유지 | 새 인식 모델/판정 로직 필요, 오인식 시 오공격 리스크 |

## 열린 질문 2 — 공격 로그(콘솔창) 유무

누가 누구를 공격했고 HP가 얼마나 깎였는지 보여주는 로그 UI.

- 있으면: 상황 파악이 쉬움, 다만 화면이 복잡해지고 4인 캠 그리드에 넣을 공간이 빠듯함.
- 없으면: 화면이 깔끔함, 다만 HP 변화의 원인을 놓치기 쉬움.

**팀 결정:**
_(여기에 채우기 — "있다"면 위치/몇 줄 노출/자동 사라짐 여부도)_

## 화면 상태별로 아직 안 정해진 것

- **MediaPipe 좌표 표시**: 손 전체 스켈레톤(관절 연결선)까지 그리는지, 아니면 점만 찍는지?
- **공격 판정 연출**: 공격 성공 시 캠 화면 위에 이펙트(파티클/화면 흔들림 등)가 있는지, 아니면 HP 바만 즉시 줄어드는지?
- **탈락 연출**: 탈락 순간 화면(흑백 처리, 탈락 문구 등) 필요한지, 아니면 지금처럼 카드가 흐려지기만 하면 되는지?
- **최종 순위 화면**: 지금은 텍스트 리스트([NinjaGamePanel.css:352](frontend/src/features/ninja/components/NinjaGamePanel.css:352))인데, 순위별 강조(1위 왕관 등) 추가할지?
- **사운드**: 공격/피격/탈락/승리 효과음을 넣을지, 넣는다면 어떤 타이밍에?
